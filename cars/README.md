# Car images

Drop three transparent PNG files in this folder:

- `car-a.png` the hero car that rides in from the left (facing right)
- `car-d.png` the car that waits on the right (facing right, the site mirrors it)
- `car-c.png` the car that rams from behind (facing right, the site mirrors it)

Tips:

- Remove the background so only the car remains (Photoshop: Select Subject, then export as PNG).
- Crop tightly so the bottom of the tires touches the bottom edge of the image.
- Resize to about 1400 px wide and compress (Squoosh or TinyPNG) so each file stays under about 600 KB.
- If a file is missing, the site keeps using the built-in vector car for that slot.
